# Security

Only the latest release is supported.

Please do not report vulnerabilities in public issues. Use
[private vulnerability reporting](https://github.com/louiscauret/temporal2mistral/security/advisories/new)
instead. This is a personal project, so I answer on a best-effort basis.

Note that `--import-check` runs the top-level code of the analysed project:
only use it on code you trust. This is expected behaviour, not a vulnerability.
